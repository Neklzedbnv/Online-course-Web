🎓 Online Courses Platform (Basic / Premium / VIP)
📌 Project Overview

This project is an Online Learning Platform that allows users to register, log in, and access courses based on their role and subscription level (Basic, Premium, VIP).

The platform is built using Node.js, Express, MongoDB Atlas, and follows a modular backend architecture with authentication, authorization, and role-based access control (RBAC).
